运维 Agent 与告警自愈

AIOps
Python · FastAPI · 大模型 Function Calling · Prometheus API · Kubernetes API · Alertmanager
  • Alertmanager 告警推给 Agent，它用只读工具（告警、Pod、事件、日志、PromQL、运维手册检索）自己排查并给出根因；从 3 种预设操作中提议处置，低风险的自动执行，其余推到 Telegram 由人确认，执行后检查是否恢复。
  • 安全靠权限而不是提示词：K8s 账号只读且看不到 Secret，命名空间白名单，日志先脱敏；写权限只开放 3 种操作，不能处理自己，同一对象 6 小时内只自动处理一次。
  • 故障演练评测：在真实集群数据上注入 OOM、备份超时、拉镜像 401 等 21 种场景。第 1 次通过率 57%，发现模型没查就编数据，加了程序核对后重测。
